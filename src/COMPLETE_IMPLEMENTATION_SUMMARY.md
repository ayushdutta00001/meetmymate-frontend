## 🚀 HOW TO USE

### **Access User Portal**
1. Start the app
2. Click "User Portal" on launcher
3. Browse services, create bookings
4. Manage profile and earnings

### **Access Admin Portal**
1. Start the app
2. Click "Admin Portal" on launcher (or add `?admin=true` to URL)
3. Login with admin credentials
4. Full governance console available

### **Navigate Admin Portal**
- **Dashboard** → Overview metrics
- **Users & Identity** → User management
- **Service Modules** → Click any service to expand 4 sub-sections
  - Operations & Control
  - Payments & Finance
  - Disputes & Reports
  - System & Security Settings
- **Audit Logs** → Complete activity trail
- **Internal Legal** → Policy repository
